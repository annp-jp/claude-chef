# chef plan cart

これは claudeのskillである /chef の buy機能についての初期構想

# 背景

現在は、出来上がった献立のプランについて `/chef plan cart` とすると買い物リストが出来上がるようになっている。
これをネットスーパーのライフでカートに追加できるようにしたいです


## 前提

* このプロジェクトへの機能追加として実現する
* Playwright MCPを利用する
* プログラミング言語は特に指定がなければ Ruby を使用する

# 要求

以下が実現できるようにしたい

## インターフェイス

* `/chef plan` によってつくられた献立が `/chef plan apply` されたあとに `/chef plan cart` を実行できる

## 機能

`/chef plan cart` を実行すると以下の段階をへてライフネットスーパーを開き、買い物リストにあるものをカートに追加していきます

* ログイン
  * ログインされている
    * 配送の予約ページへ
  * ログインされてない
    * ログインページ(https://www.life-netsuper.jp/introduction/login)から1passwordの値からログイン
* 配送の予約をとる
  * 配送予約のページ（https://www.life-netsuper.jp/delivery_select） をひらき、予約可能な時間を対話式で選択する
* リストの商品についてカートへ商品を追加していく
  * カートで商品を検索
  * カートへ追加 ※AIが判定（検索品以外のものも出てくるため）
    * 候補が一つ
      * カートへ追加
      * 数量はDBに数量のデータがないので、すべて1つ追加する
    * 候補が複数（グラム数がちがったりするので、大半がここになるはず。AIによる判定がかなり大事そう。メニューで使うお肉はこれ？っていうのがプログラムでは判断できない）
      * 対話式に解決
      * 数量はDBに数量のデータがないので、すべて1つ追加する
    * 候補がない
      * 候補がない旨をすべての商品をカートに追加後、なかったものとしてまとめて出力する
* 完了報告
  * リストの商品に足して上記のカート追加作業を行う
  * カート追加の結果を出力する
    * 追加できたものは商品名を出力
    * 追加できなかったものは項目名を出力

### 他

* 以前 `chef buy` で出していた買い物リストは `chef plan ingredient(s?)` にしたいcart-listのほうがわかりやすいかな...

# やらないこと

* skillを使用して、カートの決済を行う
* カートの数量を考慮してカートに入れる

# 検討したい

* ログイン情報の受け渡し方
* スクリプトとAIの役割分担
  * 使い分けたほうが良い気がしている
  * 例えばログインはscriptが良い気がしている
  * 検索もscriptで充分な気がしている
  * ただ検索結果からなにをカートに入れるか、検索結果から対象としても当てはまる商品候補はどれかはスクリプトには判断できないと思う...などなど
