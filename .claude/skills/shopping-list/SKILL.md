# shopping-list

## `/chef buy`

直近の確定献立から買い物リストを生成する。

### 手順

1. `ruby scripts/shopping.rb build` を実行
   - 引数なしで「直近の applied 献立」を自動選択（今日以降を含むものを優先、なければ最新の applied）
   - 特定週を指定する場合は `--week-start YYYY-MM-DD`
2. 返ってきた JSON（カテゴリ別の集計）を、ユーザー向けに整形して表示

### 出力フォーマット

```
今週（5/18〜5/22）の買い物リスト:

【肉魚】
- 鮭の切り身  4切れ
- 鶏もも肉    400g
- 豚ロース    4枚

【野菜】
- ほうれん草  1束
- キャベツ    1/2玉
...

【調味料】
- 味噌        ※在庫確認

【その他】
- 豆腐 1丁
```

注意:
- 同じ食材が複数レシピで使われている場合、scripts/shopping.rb 側で `+` で合算済（例: `200g + 200g`）。完全な数値合算はしない（単位の正規化が難しいため）
- 「確定済み献立がない」エラーが返ってきたら、ユーザーに `/chef plan apply` を案内する
- 調味料は家にあることも多いので「※在庫確認」をつけて表示するとよい
